Assignment 5 - JavaScript Basics


In this assignment, I created a simple website called My Profile using HTML, CSS and JavaScript.

The webste allows users to update their profile and add or remove hobbies.

Part 1: Profile Object and Arithmetic

I created a userProfile object with name, birthYear, isDeveloper and hobbies.

I used JavaScript to calculate the user's age and count the total number of hobbies.



Part 2: Form and Events

I created a form with Username and Birth Year inputs.

When the user clicks the Create / Update Profile button, the profile information changes.

I used addEventListener to handle the form submission.



Part 3: DOM List Manipulation

I created a list of hobbies.

The Add Item button adds a new hobby to the list.

The Remove Item button removes the last hobby.

I used JavaScript DOM methods to update the list.
